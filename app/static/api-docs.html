API Reference

The API accepts Bearer token authentication. Get a key from the Files page → API Keys section. All security management (key creation, deletion, IP reset) must be done in-app.

Authentication
Include your API key on every request:
curl -H "Authorization: Bearer <your-api-key>" ...
Keys bind to the first IP that uses them. Use Reset IP in-app if your IP changes.
POST /files/upload — Upload a file
Upload a file and receive a download link. Returns JSON with the link URL.
curl -X POST https://<host>/files/upload \ -H "Authorization: Bearer <key>" \ -F "file=@/path/to/file.txt" \ -F "original_filename=file.txt"
Optional form fields:
max_uses=10 # limit download count expires_in_seconds=86400 # link expires in 24h encryption_mode=server # encrypt at rest (adds ?ek= to URL) compress=true # zstd compress before storing is_permanent=false # mark as temporary temp_days=7 # delete after 7 days delete_if_idle_days=30 # delete if no downloads in 30 days
Response:
{ "slug": "abc123", "url": "https://<host>/file/abc123", "raw_url": "https://<host>/file/abc123/raw", "encryption_mode": "none", "file_key": null }
GET /file/{slug}/raw — Download raw bytes
Download the file directly. No authentication required (link is the credential).
curl -L -o output.txt "https://<host>/file/abc123/raw"
Server-side encrypted files require the ?ek= key from the upload response:
curl -L -o output.txt "https://<host>/file/abc123/raw?ek=<key>"
Range downloads:
curl -L -r 0-1023 -o chunk.bin "https://<host>/file/abc123/raw"
GET /file/{slug}/info — File metadata
curl "https://<host>/file/abc123/info"
Returns filename, size, content_type, encryption_mode, use_count, expires_at.
Client-side encrypted files
The key for client-side encrypted files is in the URL fragment (#ek=…) and is never sent to the server. The server streams raw ciphertext. Decrypt locally with openssl:
# PowerShell $raw = Invoke-RestMethod "https://<host>/file/abc123/raw" -OutFile enc.bin # (extract KEY from #ek= fragment of the share URL) $key = [System.Convert]::FromBase64String($KEY.Replace('-','+').Replace('_','/') + "==") # Decrypt with openssl (after converting FUPL format — use the in-app download page)
For client-side encrypted files, use the in-app download page for browser-based decryption.
